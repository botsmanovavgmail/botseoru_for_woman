BOTSEO — статический сайт

ПУБЛИКАЦИЯ
1. Выпустите/подключите SSL-сертификат для botseo.ru в панели REG.RU.
2. Загрузите ВСЁ содержимое папки botseo-site в корневую папку сайта на хостинге.
   Обычно это папка www или public_html — используйте корневую папку,
   назначенную для домена в панели REG.RU.
3. Не загружайте сам ZIP-файл вместо его содержимого.
4. Проверьте https://botseo.ru, страницы /blog/, /about/, /contacts/
   и все ссылки на мессенджеры.

SEO
- Основной адрес: https://botseo.ru/
- HTTP и www перенаправляются на HTTPS без www через .htaccess.
- Sitemap: https://botseo.ru/sitemap.xml
- Robots: https://botseo.ru/robots.txt
- После публикации добавьте сайт в Яндекс Вебмастер и Google Search Console
  и отправьте sitemap.

ПРИМЕЧАНИЯ
- Сайт статический: HTML + CSS, без базы данных и серверной логики.
- JSON-LD используется только как структурированные данные.
- В блоге опубликованы 5 статей с нумерацией 01–05.
- Исходные Markdown-файлы сохранены в content/articles/ с оригинальными именами.
- Папка content/ закрыта от индексации через robots.txt.
- Перед публикацией проверьте, что ссылки на Telegram, Max и WhatsApp
  ведут на нужные аккаунты/чаты.
